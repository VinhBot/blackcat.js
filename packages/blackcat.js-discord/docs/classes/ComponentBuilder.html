    Class ComponentBuilder<T>

    Builder hỗ trợ tạo và quản lý Discord Message Components (Buttons, Select Menus...) thông qua ActionRowBuilder.

    Class này giúp bạn:

    • Tạo component từ cấu hình JSON
    • Quản lý nhiều ActionRow
    • Disable toàn bộ components
    • Tạo collector cho component interaction

    Remarks

    Discord giới hạn:

    • Tối đa 5 ActionRow trong một message
    • Mỗi ActionRow tối đa 5 buttons
    • Select menu mỗi row chỉ được 1

    Class này tự động chia button thành nhiều row khi > 5.

    Example

    Tạo button đơn giản

    const builder = new ComponentBuilder([
      {
        type: "button",
        options: [
          {
            customId: "confirm",
            label: "Confirm",
            style: "Success"
          },
          {
            customId: "cancel",
            label: "Cancel",
            style: "Danger"
          }
        ]
      }
    ]);

    await message.reply({
      content: "Bạn có chắc không?",
      components: builder.build()
    });

    Example

    Tạo Select Menu

    const builder = new ComponentBuilder([
      {
        type: "stringmenu",
        options: {
          customId: "choose-color",
          placeholder: "Chọn màu",
          options: [
            { label: "Red", value: "red" },
            { label: "Blue", value: "blue" }
          ]
        }
      }
    ]);

    Example

    Tạo Interaction Collector

    const collector = await builder.createCollector({
      source: message,
      time: "30s",
      onCollector: async (ctx) => {
        console.log(ctx.interaction.customId);
      }
    });

    Example

    Disable toàn bộ components

    builder.disableAll();

    await message.edit({
      components: builder.build()
    });

    addRow

    • addRow(...components: T[]): ComponentBuilder<T>

      Thêm một ActionRow mới vào builder.

      Phương thức này cho phép thêm trực tiếp các component builder (ButtonBuilder, SelectMenuBuilder, ...) vào một ActionRow mới.

      Parameters

      • ...components: T[]

        Danh sách component cần thêm vào row

      Returns ComponentBuilder<T>

      ComponentBuilder instance để tiếp tục chain

      Example

      Thêm một row chứa button

      const builder = new ComponentBuilder();

      builder.addRow(
        new ButtonBuilder()
          .setCustomId("confirm")
          .setLabel("Confirm")
          .setStyle(ButtonStyle.Success),

        new ButtonBuilder()
          .setCustomId("cancel")
          .setLabel("Cancel")
          .setStyle(ButtonStyle.Danger)
      );

      await message.reply({
        content: "Bạn có chắc không?",
        components: builder.build()
      });

      Example

      Chain nhiều row

      builder
        .addRow(button1, button2)
        .addRow(button3)
        .addRow(selectMenu);

    createCollector

    • createCollector(
          options: CreateMessageComponentCollector & {
              source: Message<boolean> | ChatInputCommandInteraction<CacheType>;
          },
      ): Promise<InteractionCollector<CollectorInteraction>>

      Tạo Message Component Collector từ message hoặc interaction.

      Collector giúp lắng nghe interaction từ button hoặc select menu.

      Parameters

      • options: CreateMessageComponentCollector & {
            source: Message<boolean> | ChatInputCommandInteraction<CacheType>;
        }

        Collector options

      Returns Promise<InteractionCollector<CollectorInteraction>>

      InteractionCollector

      Example

      const collector = await builder.createCollector({
        source: message,
        time: "30s",

        onCollector: async (ctx) => {
          const interaction = ctx.interaction;

          if (interaction.customId === "confirm") {
            await interaction.reply("Đã xác nhận!");
          }
        },

        onEnd: async () => {
          builder.disableAll();

          await message.edit({
            components: builder.build()
          });
        }
      });

    disableAll

    • disableAll(): ComponentBuilder<T>

      Disable toàn bộ components trong builder.

      Phương thức này sẽ gọi setDisabled(true) cho mọi component có hỗ trợ thuộc tính setDisabled.

      Thường được sử dụng khi collector kết thúc để tránh user tiếp tục bấm button cũ.

      Returns ComponentBuilder<T>

      ComponentBuilder instance

      Example

      collector.on("end", async () => {
        builder.disableAll();

        await message.edit({
          components: builder.build()
        });
      });

    replace

    • replace(index: number, row: ActionRowBuilder<T>): ComponentBuilder<T>

      Thay thế một ActionRow đã tồn tại.

      Hữu ích khi bạn muốn chỉnh sửa layout component sau khi đã build trước đó.

      Parameters

      • index: number

        Vị trí row cần thay

      • row: ActionRowBuilder<T>

        ActionRowBuilder mới

      Returns ComponentBuilder<T>

      ComponentBuilder instance

      Example

      const newRow = new ActionRowBuilder<ButtonBuilder>().addComponents(
        new ButtonBuilder()
          .setCustomId("retry")
          .setLabel("Retry")
          .setStyle(ButtonStyle.Primary)
      );

      builder.replace(0, newRow);

      await message.edit({
        components: builder.build()
      });
