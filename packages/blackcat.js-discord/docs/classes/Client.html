    Class Client<Ready>

    Client bọc (wrap) DiscordClient: client discord.js gốc nằm ở client.discord (ví dụ client.discord.ws.ping, client.discord.user).

    Đây là class trung tâm của framework bot, chịu trách nhiệm quản lý toàn bộ hệ thống:

    • Cấu hình (config)
    • Message commands
    • Slash commands
    • Events
    • Categories
    • Các manager tương ứng

    Remarks

    Client đóng vai trò như một orchestrator, kết nối các thành phần lại với nhau:

    • Các Manager chịu trách nhiệm load tài nguyên (commands, events, ...)
    • Các Collection lưu trữ dữ liệu runtime
    • config cung cấp thông tin cấu hình toàn cục

    Lifecycle khởi động:

    1. Khởi tạo instance với ClientOptions
    2. Gọi start để load toàn bộ hệ thống
    3. Đăng nhập Discord thông qua token

    Example

    const client = new Client({
      config: {
        botToken: process.env.TOKEN!
      },
      commandManager: new CommandManager({
        directory: "./commands",
        prefix: "!"
      }),
      eventManager: new EventManager({
        directory: "./events"
      }),
      slashCommandManager: new SlashCommandManager({
        directory: "./slashCommands"
      })
    });

    await client.start();

    isAdmin

    • isAdmin(target: { permissions: Readonly<PermissionsBitField> }): boolean

      Kiểm tra xem một đối tượng có quyền quản trị viên (Administrator) hay không.

      Quyền Administrator sẽ bỏ qua hầu hết các kiểm tra quyền của Discord và cho phép thực hiện gần như mọi hành động trong máy chủ.

      Parameters

      • target: { permissions: Readonly<PermissionsBitField> }

        Đối tượng chứa tập quyền (permissions) cần kiểm tra.

      Returns boolean

      true nếu đối tượng có quyền PermissionFlagsBits.Administrator; ngược lại trả về false.

      Example

      if (client.isAdmin(member)) {
          console.log("Người dùng là quản trị viên.");
      }

      Example

      client.on("interactionCreate", async (interaction) => {
          if (!interaction.inGuild()) return;

          const member = interaction.member;

          if (!client.isAdmin(member)) return interaction.reply({
             content: "Bạn không có quyền sử dụng lệnh này.",
             ephemeral: true,
          });

          // Xử lý lệnh...
      });

    setConfig

    • setConfig(config: Partial<Config>, options?: { merge?: boolean }): Config

      Thiết lập hoặc cập nhật cấu hình bot.

      Phương thức này cho phép:

      • Gán mới toàn bộ config
      • Hoặc merge thêm config vào config hiện tại

      Parameters

      • config: Partial<Config>

        Cấu hình mới hoặc một phần cấu hình

      • Optionaloptions: { merge?: boolean }

        Tùy chọn cập nhật

        • Optionalmerge?: boolean

          Có merge với config hiện tại hay không

      Returns Config

      Config sau khi đã được cập nhật

      Remarks

      • Nếu merge = true: → config mới sẽ được merge vào config hiện tại (shallow merge)
      • Nếu merge = false (mặc định): → config cũ sẽ bị ghi đè hoàn toàn

      Lưu ý:

      • Không tự động gọi lại login
      • Nếu thay đổi botToken, bạn cần gọi lại start hoặc login

      Example

      client.setConfig({
        botToken: "new-token"
      });

      Example

      // Merge thêm config
      client.setConfig({
        debug: true
      }, { merge: true });

    start

    • start(): Promise<string>

      Khởi động bot.

      Quy trình:

      1. Load slash commands
      2. Load message commands
      3. Load events
      4. Đăng nhập Discord

      Returns Promise<string>

      Promise resolve với token sau khi login thành công

      Throws

      Error nếu token chưa được thiết lập

      Remarks

      Token được resolve theo thứ tự ưu tiên:

      1. Token đã set bằng setToken
      2. config.botToken

      Nếu không có → throw error

      Example

      await client.start();
