    Class CommandManager

    Quản lý hệ thống prefix command cho Discord bot.

    Class này chịu trách nhiệm:

    • Load command từ thư mục.
    • Đăng ký command, alias và category vào client.
    • Resolve command theo tên hoặc alias.
    • Tự động xử lý event messageCreate.
    • Kiểm tra cooldown và permission trước khi chạy command.

    Example

    const manager = new CommandManager({
      directory: "./commands",
      prefix: "!",
    });

    await manager.loadAll(client);

    • createCommand(imported: any): CommandBuilder<any, any>
      Internal

      Tạo command từ module đã import.

      Hàm này hỗ trợ hai kiểu export:

      • Export object command trực tiếp.
      • Export class command, khi đó hàm sẽ tự khởi tạo bằng new.

      Returns CommandBuilder<any, any>

      Example

    disable

    • disable(commandName: string, guildID: string | string[]): boolean

      Tắt một lệnh trong một hoặc nhiều guild. Có thể truyền tên lệnh hoặc alias.

      Người dùng gọi lệnh bị tắt sẽ nhận thông báo "đã bị tắt" (tuỳ biến bằng disabledResponse). Trong DM lệnh không bị ảnh hưởng. Trạng thái lưu trong bộ nhớ — dùng onToggle + importDisabled() nếu cần lưu bền vững.

      Parameters

      • commandName: string
      • guildID: string | string[]

      Returns boolean

      false nếu không tìm thấy lệnh.

      Example

      client.commandManager.disable("ping", "123456789012345678");
      client.commandManager.disable("ping", [guildA, guildB]);

    loadAll

    • loadAll(): Promise<void>

      Load toàn bộ command từ thư mục đã cấu hình.

      Nếu registerMessageCreateEvent là true, hàm này cũng tự động gắn listener cho event messageCreate để bot có thể xử lý prefix command.

      Returns Promise<void>

      Promise hoàn tất sau khi toàn bộ command hợp lệ được load.

      Example

      const manager = new CommandManager({
        directory: "./commands",
        prefix: "!",
      });

      await manager.loadAll();
      console.log(`Đã load ${manager.getCommandCount()} command`);

    registerCommand

    • registerCommand(
          command: CommandBuilder<any, any> | CommandBuilder<any, any>[],
      ): void

      Đăng ký một hoặc nhiều command vào command manager.

      Nếu command hoặc alias đã tồn tại, hàm sẽ ném ra lỗi.

      Parameters

      • command: CommandBuilder<any, any> | CommandBuilder<any, any>[]

        Command hoặc danh sách command cần đăng ký.

      Returns void

      Throws

      Ném ra lỗi nếu:

      • Tên command bị trùng lặp.
      • Alias bị trùng lặp.
      • Command không hợp lệ.

      Example

      manager.registerCommand(pingCommand);

      Example

      manager.registerCommand([
        pingCommand,
        helpCommand,
        avatarCommand,
      ]);

    resolve

    • resolve(commandName: string): CommandBuilder<any, any> | null

      Resolve command từ tên command hoặc alias.

      Tên truyền vào sẽ được trim và chuyển về chữ thường trước khi tìm kiếm.

      Parameters

      • commandName: string

      Returns CommandBuilder<any, any> | null

      Command tìm được, hoặc null nếu không tồn tại.

      Example

      if (commandFromAlias) {
        await commandFromAlias.execute(client, message, []);
      }

      }
