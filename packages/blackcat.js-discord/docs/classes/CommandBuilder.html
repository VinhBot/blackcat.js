    Class CommandBuilder<InGuild, TArgs>

    Builder dùng để cấu hình và thực thi message command.

    Remarks

    Hỗ trợ cấu hình tên, alias, mô tả, category, cooldown, quyền hạn và argument. Các setter trả về chính instance để có thể nối chuỗi lời gọi.

    Example

    const command = new CommandBuilder()
      .setName("say")
      .setDescription("Gửi lại nội dung")
      .setOptions((a) => ({
        text: a.string({ required: true, rest: true }),
      }))
      .setExecute(async (client, message, args, options) => {
        await message.reply(options.text);
      });

    setOptions

    • setOptions<T extends Record<string, any>>(
          options: (arg: ArgumentFactory) => T,
      ): CommandBuilder<InGuild, T>

      Khai báo các argument có kiểu cho command.

      Type Parameters

      • T extends Record<string, any>

        Object định nghĩa argument.

      Parameters

      • options: (arg: ArgumentFactory) => T

        Callback nhận factory và trả về các định nghĩa argument.

      Returns CommandBuilder<InGuild, T>

      Builder được tham số hóa bằng các định nghĩa argument mới.

      Remarks

      Nên gọi trước CommandBuilder.setExecute để TypeScript suy luận chính xác kiểu của options trong handler.

      Example

      builder
        .setOptions((a) => ({
          user: a.user({ required: true }),
          reason: a.string({ rest: true }),
        }))
        .setExecute((client, message, args, options) => {
          // options.user là User; options.reason có thể là null.
        });
