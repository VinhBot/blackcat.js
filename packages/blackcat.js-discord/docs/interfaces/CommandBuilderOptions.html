    Interface CommandBuilderOptions<T, TArgs>

    Các tùy chọn dùng để khởi tạo CommandBuilder.

    interface CommandBuilderOptions<
        T extends boolean = boolean,
        TArgs extends Record<string, any> | undefined = undefined,
    > {
        aliases?: string[];
        category?: string;
        commandName?: string;
        cooldown?: CooldownConfig<"message">;
        description?: string;
        execute?: (
            client: Client<true>,
            message: OmitPartialGroupDMChannel<Message<T>>,
            args: string[],
            options: ArgumentResult<TArgs>,
        ) => any;
        options?: (arg: ArgumentFactory) => TArgs;
        permission?: PermissionConfig<"message">;
        usage?: string;
    }

    Optionaloptions

    options?: (arg: ArgumentFactory) => TArgs

    Khai báo argument có kiểu cho lệnh. Khi có options, thư viện sẽ tự parse tin nhắn, kiểm tra giá trị và báo lỗi cho người dùng nếu nhập sai — execute chỉ nhận dữ liệu đã hợp lệ.

    Thứ tự khai báo chính là thứ tự người dùng nhập. Hãy đặt options trước execute để TypeScript suy ra kiểu chính xác.

    Example

    options: (a) => ({
        user: a.user({ required: true }),
        days: a.integer({ min: 1, max: 7 }),
        reason: a.string({ rest: true }),
    }),
    execute: (client, message, args, options) => {
        options.user;   // User
        options.days;   // number | null
        options.reason; // string | null
    }
