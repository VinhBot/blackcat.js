    Function parseTime

    • parseTime(input: string | number): number

      Phân tích (parse) một chuỗi thời gian dễ đọc hoặc số thành milliseconds.

      Hỗ trợ nhiều đơn vị thời gian, alias (tên thay thế), số thập phân và các biểu thức thời gian kết hợp.

      Nếu truyền vào number hoặc chuỗi số, giá trị sẽ được hiểu là giây.

      Các đơn vị được hỗ trợ:

      • ms, millisecond, milliseconds
      • s, sec, secs, second, seconds
      • m, min, mins, minute, minutes
      • h, hr, hrs, hour, hours
      • d, day, days
      • mo, month, months
      • y, yr, yrs, year, years

      Hỗ trợ biểu thức kết hợp: 1h 30m, 2day 5hour, 1year 2month

      Hỗ trợ số thập phân: 1.5h, 2.25day

      Parameters

      • input: string | number

        Giá trị thời gian cần chuyển đổi.
        Nếu là number hoặc chuỗi số → sẽ được hiểu là giây.

      Returns number

      Thời gian sau khi chuyển đổi sang milliseconds

      Throws

      Nếu gặp đơn vị thời gian không hợp lệ.

      Example

      parseTime("60") // 60000
      parseTime(120) // 120000

      parseTime("5sec") // 5000
      parseTime("2min") // 120000
      parseTime("1hour") // 3600000
      parseTime("3day") // 259200000

      parseTime("1hour 30min") // 5400000
      parseTime("2day 5hour") // 190800000
      parseTime("1year 2month") // 36720000000

      parseTime("1.5h") // 5400000
