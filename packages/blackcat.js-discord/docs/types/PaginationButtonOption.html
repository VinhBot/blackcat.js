    Type Alias PaginationButtonOption

    Schema mô tả một button được tạo bởi pagination.

    Object này dùng để build ButtonBuilder thông qua helper context.button().

    type PaginationButtonOption = {
        customId: string;
        disabled?: boolean;
        emoji?: string | APIMessageComponentEmoji;
        label?: string;
        style: "Primary" | "Secondary" | "Success" | "Danger" | "Link";
        url?: string;
    }
