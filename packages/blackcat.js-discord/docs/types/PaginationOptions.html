    • PaginationOptions

    Type Alias PaginationOptions<T>

    Cấu hình cho PaginationBuilder.

    Cho phép xây dựng hệ thống phân trang cho Discord message với navigation button, select menu và custom component actions.

    Example

    const pagination = new PaginationBuilder<string>({
      pages: ["Page 1", "Page 2", "Page 3"],

      renderPage: ({ data, page, totalPages }) => ({
        content: `Trang ${page + 1}/${totalPages}\n${data}`
      })
    });

    await pagination.start(message);
    type PaginationOptions<T> = {
        buildComponents?: (
            ctx: PaginationBuildComponentsContext<T>,
        ) => ActionRowBuilder<ButtonBuilder | StringSelectMenuBuilder>[];
        interactionFilter?: (
            interaction: ButtonInteraction | StringSelectMenuInteraction,
        ) => boolean;
        navigation?: {
            first?: boolean;
            jump?: boolean;
            last?: boolean;
            next?: boolean;
            prev?: boolean;
        };
        onComponent?: (ctx: PaginationComponentContext<T>) => Promise<any> | any;
        onError?: (error: unknown) => any;
        onPageChange?: (
            ctx: {
                interaction: ButtonInteraction | StringSelectMenuInteraction;
                newPage: number;
                oldPage: number;
                pagination: PaginationBuilder<T>;
            },
        ) => Promise<any>
        | any;
        onStart?: (ctx: { message: Message }) => any;
        onStop?: (ctx: { message: Message }) => any;
        onTimeout?: (ctx: { message: Message }) => any;
        pageLoader?: (page: number) => Promise<T>;
        pages?: T[];
        renderPage:
            | ((ctx: PaginationRenderContext<T>) => Promise<BaseMessageOptions>)
            | ((ctx: PaginationRenderContext<T>) => BaseMessageOptions);
        selectMenu?: {
            enabled?: boolean;
            pageLabel?: (page: number) => string;
            placeholder?: string;
        };
        timeout?: number;
    }

    Type Parameters

    • T

      Kiểu dữ liệu của mỗi trang.

    OptionalbuildComponents

    buildComponents?: (
        ctx: PaginationBuildComponentsContext<T>,
    ) => ActionRowBuilder<ButtonBuilder | StringSelectMenuBuilder>[]

    Thêm các component tùy chỉnh vào pagination.

    Dùng để thêm button hoặc select menu riêng.

    Example

    buildComponents: ({ button }) => button([
       {
           customId: "example",
           label: "example",
           style: ButtonStyle
       }
    ])

    OptionalinteractionFilter

    interactionFilter?: (
        interaction: ButtonInteraction | StringSelectMenuInteraction,
    ) => boolean

    Filter cho interaction.

    Trả về false để chặn user.

    Example

    interactionFilter: (i) => i.user.id === message.author.id

    OptionalpageLoader

    pageLoader?: (page: number) => Promise<T>

    Hàm tải dữ liệu động cho từng trang.

    Thường dùng khi dữ liệu rất lớn hoặc cần load từ database / API.

    Example

    pageLoader: async (page) => {
      return database.getUsers(page);
    }

    Optionalpages

    pages?: T[]

    Danh sách dữ liệu cho từng trang.

    Nếu cung cấp pages thì pageLoader sẽ bị bỏ qua.

    Example

    pages: [
      "Trang 1",
      "Trang 2",
      "Trang 3"
    ]

    renderPage

    renderPage:
        | ((ctx: PaginationRenderContext<T>) => Promise<BaseMessageOptions>)

    Hàm render nội dung message của mỗi trang.

    Bắt buộc phải cung cấp.

    Example

    renderPage: ({ page, totalPages, data }) => ({
      content: `Page ${page + 1}/${totalPages}\n${data}`
    })
