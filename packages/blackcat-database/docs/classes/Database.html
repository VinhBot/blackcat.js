    Class Database<V>

    Class Database cung cấp API thao tác dữ liệu dạng key-path trên nhiều loại storage khác nhau thông qua DatabaseDriver.

    Mọi thao tác đều được xếp vào một hàng đợi tuần tự, nên các lệnh gọi song song (ví dụ nhiều event cùng add() một key) không bị mất dữ liệu. Mỗi thao tác ghi chỉ đọc một lần và ghi một lần xuống driver.

    Example

    const db = new Database<Schema>({
      driver: new JSONDriver({ filePath: "./database.json" }),
    });
    await db.set("guild.123.prefix", "!");

    update

    • update<P extends string | string & {}>(
          key: AutocompletableString<P>,
          value: ObjectValue<V, P>,
          options?: { uniqueBy?: UniqueBy },
      ): Promise<If<IsObject<V>, ObjectValue<V, P>>>

      Cập nhật giá trị tại key:

      • object + object → merge nông,
      • mảng + mảng → nối thêm các phần tử chưa có (xem uniqueBy),
      • còn lại → ghi đè.

      Type Parameters

      • P extends string | string & {}

      Parameters

      • key: AutocompletableString<P>
      • value: ObjectValue<V, P>
      • Optionaloptions: { uniqueBy?: UniqueBy }
        • OptionaluniqueBy?: UniqueBy

          Cách loại trùng khi nối mảng: danh sách field hoặc hàm. Mặc định tương thích cũ (username + guild).

      Returns Promise<If<IsObject<V>, ObjectValue<V, P>>>

      Example

      await db.update("user.profile", { age: 25 });
      await db.update("members", [{ id: 1 }], { uniqueBy: ["id"] });
