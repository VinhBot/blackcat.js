# 🐈‍⬛ blackcat.js-database

A lightweight, fast, and simple **JSON-based database** for Node.js.  
Designed for small to medium projects that need persistent storage **without setting up a full database**.

---

## ✨ Features

- 📦 **JSON file storage** – simple and human-readable
- ⚡ **Lightweight & fast** – no external dependencies
- 🧩 **Easy to use API** – minimal learning curve
- 🔒 **Auto file creation** – no manual setup required
- 🔄 **CRUD operations** – Create, Read, Update, Delete
- 🛠 **Perfect for** bots, small apps, prototypes, and tools

---

## 📦 Installation

Using npm:

```bash
npm install blackcat.js-database
```
Or using yarn:
```bash
yarn add blackcat.js-database
```

See the full examples in both JavaScript and TypeScript [here.]()

## 🧠 Use Cases
+ Discord / Telegram bots
+ CLI tools
+ Small Node.js applications
+ Prototypes & MVPs
+ Configuration storage

## ⚠️ Limitations
+ Not designed for large-scale or high-concurrency systems
+ File-based storage (no indexing or advanced querying)
